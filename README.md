Install `pip`.
```
# For MacOSX
$ sudo easy_install pip
$ sudo pip install --upgrade pip

# For Linux
$ sudo apt-get update
$ sudo apt-get install python-pip
$ sudo pip install --upgrade pip
```

Install `edgegrid-python`.
```
$ sudo pip install edgegrid-python
```

Clone the `edgecurl` repository.
```
$ git clone https://github.com/akamai/edgegrid-curl
```
